# 章节选择模块

## 必选章节

以下章节始终包含，无需判断：

| 章节 | 说明 |
|------|------|
| 需求简述 | 1-3 句话概括 spec |
| 业务逻辑 | 模块划分 + 核心流程（Mermaid flowchart） |
| 变更记录 | 变更追溯 |

## 可选章节判断信号

分析 spec 内容，逐项检查以下信号：

| 章节 | 信号 | 判断依据 |
|------|------|---------|
| 时序图 | 多方交互 | spec 涉及 >= 2 个独立服务/模块/系统之间的调用 |
| 数据结构 | 数据变更 | spec 涉及数据库表新建/修改，或需要定义新的数据模型 |
| 边界情况 | 边界条件 | spec 的"边界条件"章节非空，或功能描述中隐含边界场景 |
| 错误处理 | 错误场景 | spec 涉及用户输入校验、外部服务调用、异步处理等可能失败的操作 |
| 扩展性设计 | 扩展要求 | spec 明确提到"未来需支持"或"预留"等扩展性要求 |
| 性能设计 | 性能要求 | spec 的验收标准中包含性能指标（如响应时间、吞吐量） |

## 输出格式

返回选择结果，供用户确认：

```
章节选择结果：
- [必选] 需求简述
- [必选] 业务逻辑
- [包含] {{章节名}} — 原因: {{判断依据}}
- [跳过] {{章节名}} — 原因: {{判断依据}}
- [必选] 变更记录
```
