# 拆分判断模块

## 拆分信号

以下任意一项触发时，应检查是否需要拆分为父 spec + 多个子 spec：

| 信号 | 阈值 |
|------|------|
| 独立功能点数量 | > 5 个 |
| 数据库表变更数 | > 3 张表 |
| 涉及独立模块/服务数 | > 3 个 |
| 可独立交付的子功能数 | > 2 个 |

## 判断逻辑

分析需求内容，检查是否触发上述任一条件。

### 输出格式

返回 JSON 格式：

```json
{
  "should_split": true/false,
  "signals_triggered": ["信号1", "信号2"],
  "suggestion": "建议说明"
}
```

## 拆分维度建议

如果需要拆分，提供拆分维度建议：

- 按模块拆分（如：数据模型、业务逻辑、接口层）
- 按前后端拆分（如：后端 API、前端页面）
- 按职责拆分（如：权限校验、数据管理、报表生成）
