# 产品定位与 AI 教学原则（苏格拉底原则）

## 核心定位

sisterStudy 是为单一用户（开发者妹妹，初中生）定制的学习工具，运行在安卓平板，配合平板系统级未成年人模式使用。核心闭环：

**拍错题 / 拍笔记 → 苏格拉底式引导解题 / 归档标注 → 出题检验（真题优先，AI 兜底）→ 练习自评 → 错题沉淀 → 间隔复习 → 薄弱点交叉分析 → 反哺出题**

## 统一检验问题（所有功能准入标准）

> **"这个功能是在替她思考，还是让她思考？"**

每个 AI 功能、每段 prompt、每个 UI 改动必须过此检验。答案会泄露的、允许跳过思考直达结果的，一律打回。

## 三条产品原则

1. **先提示后答案**：AI 输出预生成的「引导阶梯」，每级需用户主动触发才前进；最终答案揭示前设「答案门槛」（先提交自己的答案，可跳过但记录跳过行为）
2. **零娱乐元素**：无信息流、无社区、无游戏化诱导。防沉迷依赖平板系统级管控，App 内不做（可被绕过，不投成本）
3. **个性化注入**：prompt 必须注入学生画像（年级 + 该知识点历史错误根因），让引导针对她的薄弱点设计——这是本产品相对通用 AI 对话产品的不可替代性

## 苏格拉底式引导的实现规范

### 引导树（一次生成，逐级揭示）

- 一次 LLM 调用生成完整引导树（JSON）：诊断提问 + 3~5 级由远及近的阶梯 + 每级分支提示 + 完整分步讲解 + 答案
- 客户端按状态机逐级揭示，**不二次调用 LLM**（异步队列架构下的正确工程决策）
- 阶梯设计：第 1 级任何人能答（问条件/目标），最后 1 级只差一步计算
- 演进：M1 简化两段式 → M2 完整阶梯 + 结构化选项 → M3 真·多轮自适应

### 结构化选项即诊断数据

- 每级引导用选择题呈现（平板打字不现实），**错误选项必须映射真实常见误解**
- 选项 → 错误根因映射：概念模糊（诊断提问就错）/ 思路偏差（方向选项选错）/ 计算习惯（方向对答案错）
- 引导路径埋点（每级选项、提示次数、卡点、是否跳过答案门槛）写入 solution_log——**引导式设计不是加摩擦，是装传感器**

### Prompt 硬约束

- 角色声明：一对一引导者，不是答题器
- 教学法数据化：阶梯/选项/误解映射全部结构化输出（JSON），不是散文
- **最终答案只允许出现在 answer 字段**——用回归测试集验证泄露率
- 语气鼓励不评判，语言难度适配年级认知水平
- Prompt 随云函数 git 版本化管理，维护 10 道真题回归测试集

## 各功能的苏格拉底体现

| 功能 | 苏格拉底体现 |
|------|------------|
| 拍照解题 | 引导阶梯 + 答案门槛（见上） |
| 练习作答 | 先作答后对照；自评含「为什么错」（概念没记住/方法不会/算错了）——自我诊断 |
| 间隔复习 | 先看题笔算，后揭示解答（检索练习） |
| 出题工作流 | 基于她自己的笔记出题（考她学过的）；搜真题优先（贴合考试风格） |
| 薄弱点分析 | 笔记 × 错题交叉：「有笔记但常错」= 学过但不会用，「无笔记且错」= 可能漏学 |

## 明确不做

同步教材课程、题库建设、语音交互、作文批改、多用户体系、社交分享、上架应用商店。
