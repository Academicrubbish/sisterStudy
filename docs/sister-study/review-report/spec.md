# 复习分析与家长区 Spec

## 背景

错题沉淀后的巩固与反馈环节。间隔复习采用 SM-2 遗忘曲线调度（Toolbox 知识库第五期规划思路的落地，代码新写）；薄弱点分析利用引导路径埋点（socratic-solve 的传感器数据）+ 笔记×错题交叉（知识盲区检测雏形）；家长区为哥哥提供透明的学情视图——因独立云空间，Toolbox 小程序无法直查数据，家长区做在 App 内，口令进入。

## 目标

错题按遗忘节奏安排复习且调度受掌握深度影响；哥哥每周能看到妹妹的学习行为报告并可诊断薄弱点；所有分析数据来自真实行为埋点而非 AI 臆测。

## 功能描述

### 间隔复习（SM-2）
- review_schedule 集合：question_id、ef（易记因子）、interval（间隔天数）、reps（次数）、next_review_at
- 新错题入队：ef=2.5、interval=1
- 复习模式（复用 exercise 的自评组件）：
  - 先只显示题目 → 妹妹笔算 → 点「看解答」→ 对照
  - 自评三档：记不清 / 会了 / 很简单 → 更新 SM-2 参数（记不清重置 interval，会了按公式递增，很简单加速递增）
- **掌握深度因子**：解题时的引导路径数据参与调度——一次提示就会 vs 五级提示才过，同为"会了"但间隔增幅不同
- 首页显示「今日待复习 N 题」；错过当日顺延并标记

### 薄弱点分析
- 根因统计（行为计算值优先，AI 初判兜底）：概念模糊 / 思路偏差 / 计算习惯占比
- 知识点交叉分析：
  - 有笔记、常错 →「学过但不会用」→ 建议出应用型/变式题（联动 exercise）
  - 无笔记、常错 →「可能漏学」→ 建议补笔记/看课本
  - 有笔记、少错 → 掌握良好
- 每周报告：错题知识点分布、新增/解决数、复习完成率
- 「针对薄弱点出题」入口（联动 exercise）

### 家长区（App 内，口令进入）
- 入口：设置页深处（连点版本号或口令），避免妹妹常逛；口令哈希存 device_user
- 只读看板：
  - 每日拍题量 / 笔记量 / 解题量、复习完成率、近 7 天趋势
  - 知识点分布、根因分布、真题/AI 出题占比
  - 行为信号：跳过答案门槛频次、乱点检测命中（投入度参考）
  - API 用量与告警（自 capture 用量监控）
- getReport 云函数聚合查询，家长口令校验后返回

## 边界条件

- App 内不做防沉迷/时长限制（平板系统级未成年人模式兜底，App 内做可被卸载绕过）
- 家长区只读，不提供远程控制（下发的题目/指令会破坏"让她思考"的原则）
- 报告数据依赖埋点完整性：埋点缺字段时该维度显示"数据不足"而不是估算填充
- SM-2 参数调整需谨慎：错题量少的早期（< 20 题）调度意义有限，先积累数据

## 验收标准

1. 复习调度正确：自评「记不清」次日重现，「很简单」间隔显著拉长（单元测试覆盖 SM-2 计算）
2. 掌握深度因子生效：不同引导路径的同评级行为产生不同 next_review_at
3. 交叉分析能区分三类知识点（有笔记常错/无笔记且错/掌握良好），用测试数据验证
4. 家长口令进入看板，数据维度完整；妹妹正常使用路径无法误入
5. 哥哥实际每周查看一次报告（真实使用验收）
