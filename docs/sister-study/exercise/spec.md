# 出题工作流与练习 Spec

## 背景

出题是学习闭环的「检验」环节：基于妹妹自己的笔记与错题出题，考她学过的东西。工作流采用「真题优先」策略——真题质量（尤其数学）高于 AI 生成且贴合考试风格，先联网搜索真题（智谱 GLM 自带 web_search_tool），由 AI 评估提取是否可用，不可用则 AI 依据她的笔记上下文生成并自验。架构复用任务队列 + 定时触发器模式（task_type=exercise）。

## 目标

从错题、笔记、薄弱点三个入口触发出题，产出来源可溯（真题/AI）的练习题；妹妹作答自评后，错题自动流转错题本进入复习队列，完成「检验 → 沉淀」闭环。

## 功能描述

### 触发入口
- 错题详情页「来一道类似的」：以该题知识点 + 她的错题为上下文
- 笔记详情页「基于这篇笔记出题」：以笔记内容 + 相关笔记为上下文
- 薄弱点页「针对薄弱点出题」（review-report 交付后接入）：以薄弱知识点 + 历史错误根因为上下文

### 出题工作流（processExercise，定时消费）
```
1. 组装上下文：知识点 + 向量召回的相关笔记片段 + 相关错题（embedding 检索）
2. 调 GLM（开启 web_search_tool）联网搜索真题
3. AI 评估提取：搜索结果能否构成条件完整、自洽的题目？
   ├─ 能 → 采用，source_type=real，存来源链接
   └─ 不能 → AI 依据笔记上下文生成，source_type=ai
       └─ 自验：AI 解一遍自己出的题，解不出/答案矛盾则重出（最多 2 次）
4. 新题与已有 question/practice_log embedding 去重
5. 写入 practice_log（题目、来源、related_note_id/question_id），状态待作答
```
- 全程标注 source_type（real / ai）与 source_url，练习页和家长区可见来源
- 搜索召回不稳定由步骤 3 兜底：最坏情况退化为纯 AI 出题，工作流永不失败

### 练习作答
- 待作答列表 + 详情页：展示题目 → 妹妹纸上作答 → 点「看答案」→ 对照解析
- 自评两问（复用 review 的自评组件）：
  1. 对了吗？（对了 / 错了）
  2. 为什么错？（概念没记住 / 方法不会 / 算错了）——自我诊断，苏格拉底式元认知
- **做错自动创建 question（origin=practice）进入错题本**，随即加入复习队列
- 作答结果、自评写入 practice_log

### 用量控制
- 每次出题含搜索 + 生成 + 自验，成本高于解题：单日生成上限（默认 10 题），超出提示明日再练

## 边界条件

- 不建题库（AI 生成 + 搜索即用，不做题目资产沉淀）
- 真题版权：仅个人使用，真题展示时标注来源；不做批量抓取
- 文科（概念记忆类）可跳过搜索直接生成（优化项，按题型判断）
- 搜索 + 评估 + 生成串行约 20-40 秒，必须异步；客户端轮询展示「正在找题…」

## 验收标准

1. 三个入口都能产出一道可作答的题，全流程（触达 → 可作答）≤ 60 秒
2. 来源标注正确：真题带可访问来源说明，AI 生成题自验通过
3. 做错的练习自动出现在错题本（origin=practice）并进入复习队列
4. 出题依据可溯：practice_log 关联 related_note_id / question_id
5. 家长区可统计真题/AI 占比
